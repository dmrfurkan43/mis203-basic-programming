Week 4 Lab: Savings Goal Planner

Description

This Python program simulates monthly savings growth using an interest rate and a monthly deposit. It prints the interest earned and the new balance for each month.

The program stops when the savings goal is reached or after 60 months.

Test and Improvement

* Test: Starting balance = 1000, monthly deposit = 500, interest rate = 1%, savings goal = 3000.
* Expected result: The goal is reached in 4 months with a final balance of 3070.80.
* Change after testing: I checked the stopping condition to ensure the program stops when the balance is equal to or greater than the savings goal.

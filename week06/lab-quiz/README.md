# Week 06 – Student Club Management System

## Description
In this assignment, I created a simple Student Club Management System using Python lists and tuples.

## Features
- Created a tuple containing three main club branches: Software, Design, and Marketing.
- Created an empty list to store student records.
- Added three students manually using nested lists.
- Used `strip()` to remove unnecessary spaces from student names.
- Added the club president to the beginning of the list using `insert()`.
- Used `len()` to display the total number of registered students.
- Removed students using `remove()`.
- Used `pop()` to remove the last registered student.
- Added a new student named Burak Tan.
- Used `sorted()` to display a temporary alphabetical list.
- Used `sort()` to permanently sort the original list.

## Python Concepts Used
- Tuples
- Lists and Nested Lists
- append()
- insert()
- strip()
- len()
- for loops
- if-else statements
- remove()
